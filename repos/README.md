# Repos

Nested local repositories kept with these dotfiles.

```text
stdmk   git@github.com:njlane314/stdmk.git
        Standard Unix-shaped repository surface: ./configure, make,
        make check, make install, make clean, make distclean.

mkskel  git@github.com:njlane314/mkskel.git
        Language-extensible coding workstation with short make commands,
        source/test separation, cached builds, and bundle/run helpers.
```

These directories are intentionally ignored by the dotfiles repository. Manage
their commits and remotes from inside each nested repo.
